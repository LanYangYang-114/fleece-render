# 渲染实现说明

## 1. 渲染模式

`3d` 模式将皮肤映射到角色模型，经透视投影、CPU 光栅化和背景合成后输出 PNG。`avatar` 模式直接从皮肤展开图中采样脸部和帽子层，不创建 3D 场景。两种模式均使用最近邻纹理采样。

## 2. 玩家几何

| 部件 | 尺寸 |
| --- | --- |
| 头 | `8 x 8 x 8` |
| 头外层 | `9 x 9 x 9` |
| 躯干 | `8 x 12 x 4` |
| 躯干外层 | `8.5 x 12.5 x 4.5` |
| classic 手臂 | `4 x 12 x 4` |
| slim 手臂 | `3 x 12 x 4` |
| 手臂外层 | classic `4.5`，slim `3.5` 宽 |
| 腿 | `4 x 12 x 4` |
| 腿外层 | `4.5 x 12.5 x 4.5` |
| 披风 | `10 x 16 x 1` |
| 鞘翅单翼 | `12 x 22 x 4` |

根节点 `skin` 位于 `y=8`。头、肩部、髋部和背部装备使用 XYZ 欧拉角约定。

## 3. 相机和姿态

默认逻辑画布为 `350x670`，默认 FOV 为 70°：

| 项目 | 前视 | 后视 |
| --- | --- | --- |
| 相机位置 | `(17.9, 19.4, 37.6)` | `(-19.0, 18.1, -37.8)` |
| 注视点 | `(0, 4, 0)` | `(0, 4, 0)` |
| FOV | 70° | 70° |
| zoom | 1.0 | 1.0 |

`zoom` 通过缩放相机位置实现。前视头部略微俯仰，手臂和腿使用相位差形成自然姿态；披风默认绕 X 轴约 `10.8°`。

## 4. 纹理和 UV

- 皮肤按 `64x64` 逻辑布局处理，HD 纹理按比例采样。
- 披风和鞘翅按 `64x32` 逻辑布局处理。
- 按皮肤展开图为盒体各面分配 UV；三角形使用 `geometry.rs` 定义的绕序，以保证面朝向与背面剔除一致。
- 内层使用背面剔除；外层透明、双面并进行 alpha test。关闭 `showOuterLayer` 时，不构建六个皮肤外层盒子，装备和名称标签不受影响。
- 纹理采样使用最近邻，避免跨像素插值造成皮肤颜色污染。

### 64×32 皮肤布局转换

`64×32` 或等比例 HD 纹理在内存中转换为 `64×64` 逻辑布局：

- 复制腿和手臂到新布局；
- 清理 64×32 格式中未使用的区域；
- 保留可用于 slim 检测的透明信息。

### slim 检测

检查右/左臂四块未使用区域：

- 存在透明像素时视为 slim；
- 检测到全黑或全白的填充区域时也视为 slim；
- 其他情况使用 classic。

## 5. 光栅化

每个三角形经过以下步骤：

1. 世界坐标变换到相机空间；
2. 透视投影到屏幕；
3. 屏幕空间重心坐标和深度测试；
4. 对 UV 和深度执行透视正确插值；
5. 最近邻读取纹理；
6. 丢弃完全透明像素，执行 straight-alpha 混合；
7. 根据面朝向和固定 key light 计算简化光照。

光照由环境项、相机方向项和顶部/侧向固定光组成，足以保留立体感和服装层次。

默认 CPU 后端逐个三角形绘制。可选 GPU 后端共用投影、裁剪边界、背面剔除、光照计算与排序，将有序三角形分配到 32×32 屏幕块。计算着色器中的一个线程独立处理一个像素，按相同顺序执行深度测试、UV 采样和混合。保留最近邻、透视校正和 RGBA8 混合语义，不要求不同设备间的浮点结果完全相同。

## 6. 抗锯齿、阴影和背景

- 默认使用 2x 超采样，再使用 Triangle filter 降采样。
- 阴影从角色/名牌 alpha 生成，颜色约为 `rgba(0,0,0,0.30)`。
- `transparent=false`：先绘制白色背景，再合成角色和阴影。
- `transparent=true`：初始画布为 `rgba(0,0,0,0)`，输出 PNG 保留 alpha。
- 透明背景的判断应检查 PNG alpha 通道；查看器可能用白色棋盘格或白色画布显示透明区域。

## 7. 名称标签

- 使用内嵌的 Minecraft 像素字体；其上游仓库和转换来源见[第三方声明](../THIRD_PARTY_NOTICES.md)。
- 文字为白色，带半透明黑色背景。
- 标签作为面向相机的 Sprite 投影。
- 最大宽度为单视角宽度的 80%，超长名称等比缩小。

## 8. 2D 头像风格 `avatar`

- 双层排布：基础脸部从 `(8, 8)` 裁剪 `8×8` 后放大为 `48×48`，绘制在 `(8, 8)`；帽子层从 `(40, 8)` 裁剪 `8×8` 后放大为 `56×56`，绘制在 `(4, 4)`。裁剪坐标和区域尺寸随皮肤宽度除以 64 的倍率缩放。
- 在固定 `64×64` 的透明或白色画布上，按基础层、帽子层的顺序进行最近邻采样和 alpha 合成。关闭 `showOuterLayer` 时只绘制基础脸部，画布和基础脸部大小不变。
- 通过原始展开图判断帽子层是否有效：采样 `(1, 1)`、`(宽−1, 高−1)`、`(宽−2, 高/2−2)`；任一采样完全透明，或三个采样均不同于帽子采样 `(41×倍率, 9×倍率)` 时，保留帽子层。这可避免 64×32 皮肤的实色填充遮住脸部。
- 不转换皮肤布局，不进行光照、阴影或超采样，也不使用模型覆盖、背部装备或名称标签。

## 9. 渲染验证

`crates/fleece-render-core/tests/render_acceptance.rs` 检查 3D 输出尺寸、透明像素、确定性、模型检测与背部装备；`crates/fleece-render-core/tests/avatar.rs` 检查图层排布、透明混合及不同纹理分辨率。`crates/fleece-render-core/tests/backends.rs` 在 Vulkan 硬件上检查 GPU 重复输出、CPU/GPU 像素近似一致及不同装备和视角。运行命令和 HTTP 验收流程见[开发与验证](HANDOFF.md)。
